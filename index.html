Features

Everything you need to track your GPA

➕

Add multiple courses

Enter course name, select your letter grade from a dropdown, and add credit hours.

🧮

Weighted GPA calculation

Calculates cumulative GPA weighted by credit hours across all your courses instantly.

💾

Save and load

Save your courses to a grades.txt file and reload them any time.

✅

🔤

Full +/- grade scale

Supports A+ through F including all plus and minus grades on the standard 4.0 scale.

🛡

Input validation

Clear error messages for invalid inputs so your GPA is always calculated correctly.

How to run

Get started in 3 steps

1

Make sure Python 3 is installed on your computer. Download it here if needed.

2

Click Download ZIP above. Once downloaded, right-click the ZIP file and select Extract All to unzip it.

3

Open the file in IDLE and press F5, or run it from the terminal:
python gpa_calculator.py

GPA formula

How GPA is calculated

GPA = Total Quality Points ÷ Total Credit Hours

Quality Points per course = Grade Value × Credit Hours

Example:
Math 1314   A   3 credits → 4.0 × 3 = 12.0 pts
ENGL 1301   B+   3 credits → 3.3 × 3 = 9.9 pts
──────────────────────────────────
GPA = 21.9 ÷ 6 = 3.65
